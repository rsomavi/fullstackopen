# 0.6: New note in Single page app diagram

Diagram depicting the situation where the user creates a new note using the
single-page app version of the notes app.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User types a note and clicks Save
    Note right of browser: e.preventDefault() stops the default form submission
    Note right of browser: The browser adds the new note to its own local list of notes and rerenders the note list on the page, without waiting for the server

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (Content-Type: application/json, data: note)
    activate server
    Note left of server: Server saves the new note to its own list
    server-->>browser: 201 Created
    deactivate server
```
